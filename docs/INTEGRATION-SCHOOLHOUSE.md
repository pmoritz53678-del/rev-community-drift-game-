# Schoolhouse to Schoolyard link — read-only UI contract

The investment Schoolhouse is a separate private product governed by its own Playbook and financial ledgers. We only adapt its *room names, character-world themes and Saturday social-meet ideas* into a fictional motorsports campus. We do not copy portfolios, scores, data, names of real people or gameplay financial state into this public repository.
